# BUILTECH Conversion Audit — 2026-10-18

**Scope:** bestconstructionapps.com, evaluated against the goal in `CONVERSION_GOAL.md` (3,000 visitors/month → affiliate clicks → vendor signups).
**Method:** code review of every page template in `app/pages`, a fetch of the live site, a local production build, and the `page-cro` framework (value prop → headline → CTA hierarchy → scannability → trust → objections → friction).
**Conversion action:** an outbound click to a vendor from a tool, trade, comparison, best-for, pricing, or guide page.

---

## Executive summary

The site had the content to convert but almost no machinery to do it. Before this pass:

1. **The live site was running a stale build.** The deployed bundle predates PR #56 (July 2026). Pricing pages, blog, cost calculator, methodology, newsletter, and full-HTML prerendering all return 404 or an empty `<body>` in production. Whatever the analytics say today, they describe the old site.
2. **Some visitors were sent to the wrong place.** The `affiliateUrl` field held vendor *affiliate-program application* pages (e.g. `procore.com/partners/affiliate`). The category, pricing, and cost-calculator pages used it as the visitor link, so a contractor clicking "Visit Procore" landed on "become a Procore affiliate".
3. **The conversion event was not measured.** No GA4 event, no UTM, no `rel="sponsored"`. Outbound CTR, the north-star metric, could not be computed.
4. **The site's primary CTA was "Write a Review".** Header, homepage hero, and homepage footer all pushed user-generated content, not the revenue action. Vendor CTAs said "Visit Website".
5. **Money pages stopped short of a recommendation.** Trade pages (the "best HVAC software" landing pages) ranked tools but had no click-out. Comparisons computed a verdict but offered no next step. Guides ended in "Explore More Guides".

All five are addressed in code except #1, which is a deployment/ownership action.

## Findings in detail

### Critical

**C1. Production is stale.** `curl https://bestconstructionapps.com/` returns the old head-only shell (2.3 KB, empty body). `/pricing/jobber` and `/blog` 404. The live JS bundle contains no `cost-calculator`, `pricing/`, `blog`, or `methodology` strings. The repo builds cleanly locally (351 pages prerendered). Root cause (confirmed via the GitHub deployments API): the GitHub-connected Vercel project `cartboost/affiliate-construction-tech` deployed `main` successfully on 2026-07-12 and serves the current code at its `*.vercel.app` URLs. The custom domain resolves to Vercel but returns the old bundle, so `bestconstructionapps.com` is attached to a different Vercel project. **Owner action: move the domain to `cartboost/affiliate-construction-tech` in Vercel's domain settings.** Also hardened the build: `tsx` is now an explicit devDependency and `engines.node >= 20.11` is declared (the prerender script uses `import.meta.dirname`).

**C2. Wrong destination for affiliate CTAs.** `constructionData.ts` had `affiliateUrl: "https://www.procore.com/partners/affiliate"` for Procore, Buildertrend, ServiceTitan, Jobber, and Housecall Pro. Three page templates preferred `affiliateUrl` over `website`. Fixed by splitting the field: `affiliateProgramUrl` (owner-facing) and `affiliateUrl` (visitor tracking link, currently unset).

**C3. No measurement of the conversion.** Added `app/lib/outbound.ts` + `OutboundCta`. Every vendor link now fires GA4 `affiliate_click` with `tool_id`, `placement`, `page_path`, `link_url`, `affiliate_link`, plus Vercel Analytics when present. Plain vendor URLs get `utm_source=bestconstructionapps&utm_medium=referral&utm_campaign={slug}&utm_content={placement}` so vendors can see the traffic (useful leverage when applying to programs). Affiliate tracking links are passed through untouched.

### High

**H1. CTA hierarchy inverted.** "Write a Review" was the only orange button in the header and the homepage's closing section. Reviews are a trust asset, not the conversion. Now secondary everywhere.

**H2. "Visit Website" copy.** Replaced with `getCtaLabel()`: "Start Free Trial" (price note mentions a free trial), "Get Started Free" (free tier), "Get a Demo" (contact/custom/quote pricing), "See Plans & Pricing" (published price), else "Visit {Tool}". Labels are derived from data, so they stay truthful as pricing notes are updated.

**H3. No verdict at the decision point.** Tool pages list pros and cons and then jump to reviews. Added a "Bottom Line: Is {Tool} right for you?" block that names the trade-off from the first pro and first con, restates rating/price, and offers the CTA plus a "Compare with {closest alternative}" link (editorial comparison page when one exists, compare builder otherwise).

**H4. Trade pages had no click-out at all.** These are the pages the SERP tracker targets ("best HVAC software"). Added a Top Pick card with CTA (sticky in the desktop sidebar, first thing in the main column on phones) and a CTA on every ranked row.

**H5. Mobile tool pages buried the CTA.** The hero CTA box stacks under the description on phones. Added a sticky bottom bar (hidden when the compare bar is open).

**H7. Horizontal scroll on phones (pre-existing).** Tool, trade, and guide pages overflowed the viewport by 87–284px at 390px wide on `main` because the two-column grid children had no `min-width: 0`. Fixed on all three templates and verified at 0px overflow with viewport emulation. `/top-rated` still overflows by ~119px (an inline row that does not wrap); see M8.

**H6. Disclosure only on /about and /methodology.** FTC guidance wants it "clear and conspicuous" near the link. Added `AffiliateDisclosure` under every CTA block with a link to the methodology page. This also reads as a trust signal next to the button.

### Medium (not fixed in this pass)

**M1. Newsletter is an RSS link.** `NEWSLETTER_FORM_ACTION` is empty. Needs a provider. Then: the pricing index as a downloadable spreadsheet is the obvious lead magnet (data already in `app/data`).

**M2. Footer trust leaks.** Social icons are non-functional `<button>`s; `/privacy`, `/terms`, `/advertise`, `/review-guidelines` 404. A 404 privacy policy next to a GA4 tag is a trust and compliance gap.

**M3. "Verified" badge is unexplained.** Tool pages show a "Verified" chip with no definition. Either define it on `/methodology` and tooltip it, or remove it.

**M4. Unsourced hero stats.** Homepage "70% faster takeoffs / 35% fewer safety incidents" have no citation. Either source them or cut them; unsourced numbers reduce trust with the exact audience that distrusts vendor marketing.

**M5. Best-for pages rank but do not pick.** Add the same Top Pick treatment as trade pages.

**M6. Single placeholder author.** E-E-A-T and conversion both improve with a named reviewer and screenshots for the top 10 tools. Requires owner input (cannot be invented).

**M8. `/top-rated` overflows on phones** (~119px, pre-existing): the category chip + review-count row does not wrap. Worth fixing now that the header CTA points there.

**M7. Pre-existing TypeScript errors** (8, none in files touched here) in `ReviewModal`, `calendar`, `constructionData` (two tools typed `"Service"`/`"Data"`), `guidePages`, `schemaTypes`. The build does not run `tsc`, so they do not block deploys, but they will bite the first time someone adds a typecheck step.

## Test ideas (once `affiliate_click` has two weeks of data)

| Hypothesis | Where | Metric | Minimum sample |
|------------|-------|--------|----------------|
| Outcome labels ("Start Free Trial") beat "Visit {Tool}" | tool_hero | CTR per placement | ~200 clicks/variant |
| Top Pick above the list beats Top Pick in sidebar only | trade pages, desktop | CTR | ~150 clicks/variant |
| Verdict with a named trade-off beats a neutral summary | tool_bottom_line | CTR | ~150 clicks/variant |
| Sticky mobile bar: with price vs. without | tool_sticky | CTR, bounce | ~150 clicks/variant |
| Disclosure under CTA vs. above CTA | all | CTR (expect no loss) | ~300 clicks/variant |

At 3,000 visitors/month and an 8% CTR, that is ~240 clicks/month sitewide, so run one test at a time, sitewide, for 4–6 weeks. Do not split by page.

## Second pass (same day): technical SEO, AI-search readiness, and de-slop

**Technical SEO (crawl of the built site, 344 pages)**
- Orphan pages 78 → 0. New hubs `/best` and `/categories`; trade and tool sidebars link to the best-of lists for that trade; `/compare` lists every head-to-head page.
- Broken internal links: 7 footer links on every page (3 wrong guide slugs, `/advertise`, `/review-guidelines`, `/privacy`, `/terms`) and 13 tool links hardcoded in category content → 0. Privacy and Terms pages now exist.
- Titles over 65 characters 141 → 6 (brand suffix dropped, `shortTitle()` trims data titles).
- Duplicate products: STACK ×4, Procore ×2, FieldEdge ×2, Buildxact ×3, Jobber ×2, Knowify ×2. Identical-slug copies were unreachable and inflated trade lists; removed. Same-product variants now carry `duplicateOf`, canonicalize to the primary, are noindexed, and are excluded from the sitemap and exports.
- Sitemap `lastmod` was the build date for all 351 URLs; it is now the editorial date.
- Build hardened for Vercel: `tsx` is an explicit devDependency, `engines.node >= 20.11` declared.

**AI-search (GEO)**
- `/pricing.md`: a Markdown pricing table generated at build for AI agents, linked from `llms.txt` and the pricing index.
- `llms.txt` counts corrected (it claimed 140+ tools; the directory has ~75 after de-duplication) and new entry points added.

**De-slop design pass**
- Real vendor logos (favicon-based `ToolLogo` with initials fallback) replace colored-initials squares at 17 sites.
- Emoji removed from trade cards, chips, nav, footer, and search; dot-grid and radial-glow backgrounds removed from home, guides, and search.
- Homepage: light editorial hero with a serif headline, honest eyebrow stats, no stats bar, no "AI Spotlight" with unsourced percentages, no stock-photo trade tiles. Trade tiles show count and top pick.
- The "Top Rated This Month" module and `/top-rated` page used hand-written monthly rating deltas and reasons; both are replaced with a ranking computed from the directory (min. 100 reviews).
- "Verified" badges removed (undefined). "AI & Software Directory" lockup and "AI Search" renamed.
- Typography: Fraunces for headings, Source Sans 3 for body, loaded with `display=swap`.

**Still open for the owner**
- Move the domain to the GitHub-connected Vercel project (see Critical C1).
- A named author with a photo; screenshots for the top tools.
- Trade-page heroes and the "Why AI & Software Matter" block still use the dark gradient treatment; convert once the editorial direction is confirmed.
- Ratings and review counts in `constructionData.ts` are inconsistent across duplicate entries (e.g. Jobber 108 vs 4,521 reviews). The directory keeps the first entry for each slug; the numbers should be re-sourced from G2/Capterra before the site claims them.
